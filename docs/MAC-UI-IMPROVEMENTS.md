## 現在の共有範囲
通常・暗号化の保存済み素材、通常フォルダの鍵設定、ごみ箱による一覧除外、Macが保存した容量集計は共有される。画面反映には更新が必要な場合がある。ごみ箱の操作はMacの送信記録を持つ通常フォルダのみ。お気に入り共有とiPhoneのごみ箱操作は未実装。端末キャッシュは各端末に保持し共有しない。

## 実装境界
第1段は既存の保存方式・暗号化・本番APIの権限を変更しない。ごみ箱の一括操作は確認画面で確定した表示中対象だけを扱い、解除前の項目を削除しない。実素材の削除を検証に使わない。旧履歴の完了時刻は推測せず「記録なし」。第2・3段の未実装項目は完了扱いにしない。
