# Macの手動フォルダアップロード

2026-10-14。本人専用の非公開S3アップローダー初期版。常時同期・ファイル監視・起動時の自動再開は行わない。

## 操作

現行SwiftUIでは複数フォルダ選択・ドラッグ追加・まとめて送信予約・準備／送信進捗・大容量の分割再開を提供する。現行Macでは選択／ドラッグ後に準備と送信を自動実行し、チェック欄は不要。以下は開発用Webの従来単独操作の説明。更新内容と再開データは[アップロード改善](UPLOAD-IMPROVEMENTS.md)を参照。

1. [Mac試作](DESKTOP-OPERATIONS.md)を起動し、「設定 → S3フォルダアップロード」を開く。
2. フォルダを選択する。media-hubの既存S3バケット、photo-hubプロファイル、東京を初期値とし、履歴があれば直近の接続設定を使う。通常は接続パラメーターを入力しない。変更は折りたたみの「保存先の設定」から行う。AWS CLI v2をインストールし、先に端末で短期認証へログインしておく。秘密鍵を画面へ入力しない。
3. 「送信内容を確認する」でサブフォルダ・空フォルダ・対象メディアの件数と容量を確認する。この操作ではAWSへ接続・送信しない。
4. 送信先、費用目安、対象を確認し、確認チェックを付けて「手動でアップロード開始」。この操作は実メディアとフォルダ／ファイル名のS3送信への承認になる。
5. 途中停止は現在のファイルの完了後。失敗・再起動後は履歴から同じ転送を選び手動再開する。API起動時に中断状態を復旧するだけで、クラウドへアクセスしない。

Mac原本は常に保持。送信前に1ファイル分の一時コピーを作り、確認時のSHA-256・ファイル同一性・サイズを照合。S3への条件付き新規PUT／multipart完了後はHEADサイズとSHA-256（分割時は合成値）で照合する。既存キーが確認できれば原本を再送しない。権限エラーを「ファイルなし」と扱わない。確認後に原本が変更された場合は停止し、新しい確認からやり直す。

初期版は1ファイル5GiB、1回20GiB、素材・フォルダ各10,000件。隠しファイル・隠しフォルダ・シンボリックリンクは対象外。通常ファイルのみ扱う。主なJPEG/PNG/WebP/HEIC/GIF/TIFF、MP4/MOV/M4V/WebM/MKVを原本として保存する。拡張子による選択で、メディア内容・再生可能性の検証ではない。動画変換は別機能。現行版は非公開サムネイル生成とマルチパート送信に対応。巨大なファイルは上限を迂回せず、対応追加後に扱う。

## フォルダと保存方法

- Macの元フォルダの階層は表示用の名前・固定folder ID・parent IDとして保存。空フォルダも保持。
- 原本キーは `media-hub/originals/{assetID}/{SHA256}`。フォルダ名やMac絶対パスをキーに含めない。
- 管理JSONは `media-hub/catalogs/{rootID}/{uploadID}.json`。確認単位の変更不可スナップショット。全原本の照合後だけ登録し、管理JSONも照合するまで完了と表示しない。
- 同一Macライブラリ・送信先・元フォルダの再確認はroot IDを引き継ぎ、相対パスからfolder/asset IDを維持する。ファイル移動・改名や元フォルダ移動の同一性追跡は未実装。
- 再確認は新スナップショットとして残る。更新・削除で古い原本やJSONを自動削除しない。管理JSONだけで常時同期を行わない。
- 元フォルダの削除・改名・移動は操作しない。左メニュー「S3フォルダ」で保存完了したフォルダを階層閲覧し、画像・動画を開ける。アップロード完了画面の「保存したフォルダを見る」からも開ける。新しい未完了スキャンは保存済みフォルダを隠さない。SQLite素材一覧との統合、iOS読取、画面内改名／移動／ごみ箱は次工程。
- ローカル状態は既存SQLiteライブラリのデータディレクトリ内 `folder-uploads/` のJSON。元フォルダへ管理ファイルを作らない。Mac絶対パスは端末だけに保存。

## 非公開と料金

開始後・原本送信前に公開ブロック4項目、SSE-S3デフォルト暗号化、TLS拒否ポリシーを読み取り確認。原本と管理JSONへSSE-S3、Standardを指定。CLI stderr・署名URL・秘密値は画面やログへ返さない。Electron rendererはAWS認証情報を受け取らない。MacのAPI子プロセスから端末のAWS CLI短期認証を使う。既存の本人JWT署名APIとは別経路で、iOSへCLI認証を渡さない。

予算通知・アプリ全体の請求監視・限定IAMの整備は未完了。このアップローダーは月額2,000円上限を保証しない。1回20GiB制限は転送単位の安全策で、月間／総保存量の上限ではない。原本の旧内容、非現行版、古い管理JSON、失敗後の未登録オブジェクトも課金対象。自動削除しないため後日の棚卸しと承認した保持ルールが必要。クラッシュ時のローカル一時コピーも残る可能性があり、停止中に確認して整理する。

料金確認日2026-10-14、東京、S3 Standard従量料金、無料枠・割引なし。公式[東京価格表](https://pricing.us-east-1.amazonaws.com/offers/v1.0/aws/AmazonS3/current/ap-northeast-1/index.json)で最初50TBの保存$0.025/GB月、PUT/COPY/POST/LIST $0.0047/1,000回、GET/HEAD等$0.00037/1,000回を確認。[公式料金](https://aws.amazon.com/s3/pricing/)の保存GBは2^30 bytes（GiB）。画面は今回の原本bytes÷2^30×$0.025のみを保存料として算出。円は1 USD=150円・消費税10%の仮定でUSD×150×1.1。管理JSON・既存データ・旧版・実配信・付帯サービスを除くためアプリ総額の見積もりではない。無料枠残量は未確認で控除しない。

新規原本N件は概ねPUT N回＋管理JSON1回、HEADは原本ごとに送信前後＋管理JSON、開始時の設定確認3回。再試行・応答消失で増える。原本送信では全ファイルのダウンロードや原本GETを行わない。大容量の分割送信では断片のPUT・一覧取得が追加される。料金更新・他リージョンは再確認が必要。

## S3フォルダの閲覧

一覧は端末の保存完了カタログを読むだけでS3原本を取得しない。画像サムネイルはMacの原本を照合して320px以下のPNGを生成。動画・未対応画像形式・Mac原本欠損はプレースホルダー。素材を開いたとき、照合済みMac原本のコピーを表示し、原本がなくなった／変更された場合はカタログで固定したS3版をGETしてサイズ・SHA-256照合する。動画はcontrols・preload=metadataで自動再生しない。端末APIはRange応答に対応するが、S3取得は原本全体のGETなので視聴時間分だけの転送とはしない。

初期閲覧版の原本は100MiBまで、原本キャッシュ合計500MiBで追加取得を停止。元ファイル・S3データを削除しない。Macに原本がないサムネイルは一覧表示だけでは取得せず、原本GETは明示的な素材オープンのみ。閲覧コピーと派生はデータディレクトリのfolder-uploads/view-cacheへ保存（親ディレクトリ0700）。HTTPはprivate/no-store。アカウント切替・キャッシュ管理UIは未実装。別端末のカタログ取得と大容量動画のストリーミングは次工程。
