# MacからのS3整理・削除

## 操作
「S3フォルダ」でファイル／フォルダを右クリックして「ごみ箱へ」。フォルダ内の「選択」で複数のファイルを選び、まとめて移動できる。「このフォルダをごみ箱へ」は子フォルダ・空フォルダを含む。トップのフォルダも右クリックで移動できる。

上部の「ごみ箱」で「復元」または対象名を確認して「完全削除」。⌘クリックで複数選択して「選択した件数を完全削除」、または「表示中をすべて完全削除」を使える。確認画面で件数・原本容量を確認して確定する。解除前の項目・暗号化フォルダは対象外。確認時の対象だけを逐次処理し、失敗・再ロック時は後続を停止する。途中失敗では成功件数を表示し、残りを更新して再試行できる。一括処理は全件の原子的な成功を保証しない。ごみ箱への移動ではS3原本・小画像を保持し、通常一覧と新しい閲覧URLの発行から除外する。復元は同じ名前と階層へ戻す。自動期限・自動削除はない。Macの元フォルダと元ファイルはどの操作でも保持する。

## 完全削除と再試行
完全削除は対象原本・小画像の全バージョンと削除マーカーを列挙し、正確に一致するキーだけを削除する。S3の容量を解放するが、復元できない。小さなカタログ・過去のカタログ版・送信履歴・鍵設定は記録として保持する。バケット全体を空にする機能ではない。

開始前に全ての現行カタログを確認し、別の送信履歴が同じ原本／小画像を参照していれば停止する。その場合はごみ箱での非表示・復元を使えるが、共有される実データの完全削除はできない。共有参照のまとめて解消は今後の対応。

先にS3カタログへ「完全削除中」を条件付きで保存し、保存照合後に実データを消す。途中失敗ではごみ箱に「完全削除中（再試行可能）」が残る。復元は不可で、「完全削除を再試行」で残る版を削除する。起動時の自動削除はしない。応答を失った場合は「更新」でS3の状態を再取得する。

送信実行中の削除は拒否する。既存の署名URLは最大5分の有効期間中、ごみ箱移動後も取得できる場合がある。完全削除で実データが消えるとその版のURLも取得できなくなる。

## 鍵・競合・保存先
鍵付きフォルダの項目は解除前にごみ箱へ名前も表示しない。削除・復元では、対象の送信記録にある全ての鍵付きフォルダを先に解除する。親フォルダに既存のごみ箱項目がある場合は、先にその項目を復元してから親全体を移動する。

操作対象はこのMacに送信記録がある通常S3フォルダ。暗号化フォルダは対象外。カタログとMac送信記録の原本キー・ハッシュ・階層の一致を確認し、条件付き保存で競合時に停止する。複数Macからの同時送信・管理や、AWSコンソール等による操作との排他は未対応。同じフォルダの過去のごみ箱項目を操作しても、最新版の送信一覧を古い履歴へ巻き戻さない。

## 実装と検証
- Mac画面: `macos/MediaHubMac/Gallery.swift`、`Views.swift`、`Model.swift`
- 管理API: `local-api/vault/cloud_trash.py`、`folder_upload.py`、`app.py`
- 共通の一覧除外: `backend/catalog_trash.py`、iPhone閲覧: `backend/reader.py`
- 契約: `contracts/asset.schema.json` の `CloudTrashEntry`
- 隔離検証: `local-api/tests/test_cloud_trash.py`、`backend/tests/test_reader.py`

iPhone側への反映には閲覧Lambdaへ `reader.py` と `catalog_trash.py` の配布が必要。iPhoneアプリ自体の再インストールは不要。配布前の閲覧APIはごみ箱を認識しない。
