# PDFの送信と閲覧

Macの通常／暗号化アップロードで、選択フォルダ内のPDF（拡張子の大小文字を区別しない）を画像・動画と一緒に送信する。原本は変更せず、1ファイル250MiBまで。閲覧時に全体をメモリへ読み込むため、送信前にも同じ上限を適用する。164MiBの原本取得・暗号化全体復号と250MiBの送信境界を合成データで検証する。実PDFの描画時メモリ量は内容によって異なる。

MacはS3フォルダ／暗号化フォルダ、iPhoneは「見る」の通常／暗号化フォルダからPDFを開く。Apple PDFKitで全ページの縦スクロールと拡大縮小に対応。写真一覧・動画一覧・ランダムスワイプにはPDFを含めない。PDF自体にパスワードがある場合は、表示時に入力する。パスワードは保存しない。

先頭ページを最大320px・50KBのPNGにして保存する。PDF自体のパスワードでロックされている場合や表紙の生成に失敗した場合はアイコンと名前を表示し、原本の保存は続ける。

通常PDFは既存のS3原本照合経路を使う。Macの閲覧用一時ファイルは閲覧終了で削除し、iPhoneではPDF原本をディスクキャッシュしない。暗号化送信は原本・表紙・名前／階層を既存のAES-GCM経路で暗号化する。Mac／iPhoneとも復号後にSHA-256を照合し、PDFDocumentへメモリで渡す。閉じる・再ロック時に表示と読み込みを破棄する。OSのメモリ管理に対する保証範囲は[暗号化の制約](ENCRYPTED-UPLOAD.md)と同じ。

追加のクラウド変換サービス・ライブラリ・AWS設定変更は不要。PDF編集、注釈の保存、検索専用UI、大容量PDFの部分読み込みは対象外。
