# アップロード改善とMac暗号化閲覧UI
## Request
コピー／照合の同時処理、少数並列、複数フォルダ予約、ドラッグ追加、準備／送信進捗と残り時間、大容量の分割送信・途中再開を通常／暗号化へ追加。中断後の現状確認と続行、暗号化閲覧UIの統一。
## Investigation
既存の逐次処理、重複読取、AWS CLI、SHA-256照合、暗号化nonceと再開条件を確認。AWS公式仕様とインストール済みCLIのmultipart・チェックサム・条件付き完了対応を確認。Macは旧版が動作中で、見つかったクラッシュ記録は以前のEnvironmentObject問題だった。バックグラウンド更新が画面全体を操作不可にする箇所を確認。
## Changes
- コピーとハッシュの同時処理、照合済みスナップショットから通常小画像生成。
- 非同期確認、段階・容量・並列数・時間目安、上限2件の並列（大容量は単独）。
- 複数選択・親子の重複選択整理・ドラッグ追加・確認後のフォルダ予約。停止／失敗時は後続も停止。
- 64MiB以上を16MiB単位でmultipart。S3断片のSHA-256と合成値、全文ハッシュ、サイズを照合し条件付き完了。期限切れに対応。
- 暗号化の再開用暗号文だけを保持し、同じ鍵と同じ暗号文で再開。成功後に除去。鍵・平文は永続保存しない。
- バックグラウンド更新中も操作できるようにし、古い応答の上書きを拒否。
- Mac暗号化閲覧に通常と同じ左右ボタン／矢印キー・Esc・件数表示・黒背景を追加。鍵設定を折りたたむ。
## Files Changed
local-apiのfolder_upload／encrypted_upload／multipart_upload／app、関連テスト、MacのModel／Views／SealedViews、共通契約と型生成、正本ドキュメント、decisions/0018。
## Validation
- verify-desktop全体成功: Python API111件、backend31件、Swift21件（実AWSの任意試験1件skip）、契約・文書・Macビルド。
- 旧送信計画の合成ハッシュを送信記録から復旧する互換性を追加し、改善テスト15件・通常送信31件を再実行して成功（全体検証から新規1件追加）。
- Web build成功。既定Node16ではVite実行失敗したため、既存のHomebrew Node24で成功。
- iOS Simulator署名なしビルド成功。初回はsandboxのXcode cache／Simulatorアクセスで失敗し、通常環境で成功。
- 隔離Macと生成画像・ローカル模擬S3で、複数フォルダ選択、確認中の進捗、予約の名前／容量／保存先、確認チェック前の開始禁止とチェック後の有効化を確認。実送信は画面から行わない。
- 制限環境のloopback試験は失敗したため通常環境で成功。個人メディアの送信・削除なし。
## Result
更新Macをビルド・起動。模擬S3では通常／暗号化の再起動後の分割再開、送信済み断片の省略、原本保持、暗号文同一性、停止と失敗後の予約停止を確認。
