# Mac UI改善・第1段
## Request
費用グラフ、追加の待ち・小さいボタン、保存結果、フォルダの暗号化状態、切替時の消失、お気に入り共有、Macキャッシュ、ごみ箱一括削除と端末共有を全課題化し、影響が小さい優先項目からまとめて実装。テストは最後。
## Investigation
ごみ箱の完全削除は項目単位のみ。Macでの通常ごみ箱操作は共有カタログを更新しiPhoneの一覧除外に反映するが、iPhoneのごみ箱操作・暗号化ごみ箱・共有お気に入りは未実装。既存の未コミット変更は保持して追加編集した。
## Changes
12課題を優先度・影響・段階で整理。第1段として追加結果を完了日時（日本時間）・登録件数・容量・重複数中心へ整理し履歴を折りたたみ、ボタンを拡大。完了日時は成功確定後だけ記録、旧履歴は推定しない。フォルダの通常／暗号化を明示。ごみ箱は確認対象を固定して逐次削除し、失敗・再ロック時に停止。容量・費用画面は保存費を先頭に、7／30／90日切替、日別数値、通信記録の折りたたみを追加。
## Files Changed
MacのViews・Model・Gallery・SealedViews・新規TrashBatch、共通UsageDashboard、FolderUpload契約と生成型、通常／暗号化アップロード完了日時、関連テスト、UI課題・操作・検証文書とCURRENT。
## Validation
最後にまとめて実行。ローカルAPI207件成功、backend42件成功。Swift38件成功（実AWS1件skip）。Macアプリビルド成功。契約生成一致・文書full・差分空白確認成功。初回は隔離環境のローカル接続／描画制限で失敗したため権限を調整して再実行し成功。iOS Simulatorビルド成功。
## Result
影響の小さい第1段を実装し、Mac更新ビルドを作成。実素材の送信・削除、AWS配布、実機更新、稼働中アプリの再起動はしていない。
## Remaining Issues
実画面の視認性と複数選択・取消・期間切替は手動未確認。完了日時は旧履歴にはない。第2段のキャッシュ・通常画面保持・速度計測・検索等と、第3段の共有お気に入り・iPhoneごみ箱操作・暗号化ごみ箱は未実装。全課題はdocs/MAC-UI-IMPROVEMENTS.md。
