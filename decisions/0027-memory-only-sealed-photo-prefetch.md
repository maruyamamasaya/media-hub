# 0027: 暗号化写真のメモリ限定先読み
Date: 2026-10-16
Status: accepted
## Context
本人が復号画像を端末へ保存しない先読みと、利用料増加を抑えた改善を依頼した。
## Decision
画面単位で復号画像と取得タスクを共有。接続確認済みの非従量Wi-Fi／有線だけで直後1枚・5MiB以下を先読みし、ヘッダー／タグを含む50MiBの解除中予約予算を使う。設定で停止可能。通常ディスクキャッシュに入れない。
## Reason
同じ画像の二重取得・復号とページ移動後の待ちを減らし、未閲覧素材の大量取得を防ぐ。閉じても予算を返却せず、繰り返し開く操作で自動先読みが増え続けないようにする。
## Alternatives
全フォルダ先読み、携帯回線での自動取得、平文ディスク保存は採用しない。原寸の無制限展開も避け、表示画像を長辺4096px以下・保持合計128MiBへ制限する。
## Consequences
現在／前／次のうち容量内だけを保持し、画面終了・背景・再ロック・鍵変更時は取消／参照破棄する。メモリ警告は隣を破棄して先読み停止。再訪では再取得する場合があり、料金ゼロ・月額上限・OS管理メモリの消去を保証するものではない。詳細は[仕様](../docs/S3-READER.md)。
