# 0019: 費用画面の共有集計と端末の通信記録
Date: 2026-10-14
Status: accepted

## Context
本人から費用をグラフ化しMac・iPhoneで閲覧したい、通信回数をアプリで記録できるという要望があった。アプリ別の請求配賦と全動画の実転送量は取得できていない。
## Decision
Macの手動集計を非公開S3に保存し、iPhoneは本人APIで読む。保存量／保存費試算とアカウント全体予算を区別し、各端末の通信回数と計測済み受信量は端末内に保存する。通常動画は再生開始回数を別表示する。
## Reason
素材の取得や新しい有料監視サービスを加えず利用量を見える化できる。通信回数から転送量や請求額を誤って断定しない。
## Alternatives
S3の追加メトリクス、Cost Explorerによる費用配賦、端末間の活動集計は今回は採用しない。必要な費用と欠測の扱いを定めてから追加する。
## Consequences
Mac更新まで共有保存量は古いまま。通信記録は導入後の端末ごとの部分計測で、AWS請求を再現しない。集計JSONの旧版と更新通信にも従量費用がある。詳細は [操作と計測範囲](../docs/USAGE-DASHBOARD.md)。
